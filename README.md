# Personal Workbench

Personal Workbench 是一个仅监听本机回环地址的个人助理工作台。当前版本包含消息提醒、任务计划、Skill 管理、商务对接、经验复盘和 AI 新闻资讯。

## 启动

在 PowerShell 中执行：

```powershell
cd D:\AI-Codex-Projects\personal-workbench
.\scripts\start-local.ps1
```

浏览器地址：<http://127.0.0.1:5173/>。

手动启动时可以分别执行 `pnpm start:server` 和 `pnpm dev -- --port 5173`。首次启动会自动执行数据库迁移。停止后台进程可在任务管理器中结束本次启动的 `node` 进程，或使用前台命令并按 `Ctrl+C`。

## 当前能力

- 任务计划：记录个人待办、计划和想法，按“计划时间已过、今天处理、等待/受阻、未来 7 天”聚焦跟进，支持完成、软删除和恢复。
- 消息提醒：统一汇总工作台通知；任务计划提前 3 天提醒，商务合作和商务跟进提前 7 天提醒，截止当天升级为紧急提醒；支持已读、稍后提醒、忽略、推进、延期和取消或终止。
- Skill 管理：列出实际可发现的 Skill，区分系统/插件/已安装/自己生成等来源，启停、打开目录；可删除项会先禁用，再将整个目录移入 Windows 回收站。
- 商务对接：管理公司、联系人、销售机会、合作项目、沟通记录和跟进事项；可粘贴沟通材料，经 AI 生成草稿并确认后写入。
- 经验复盘：记录事情回顾、做对做错、经验总结与下次改进。
- AI新闻资讯：接收 AI Weekly 自动推送的结构化周报，默认阅读最新一期完整内容并可按周回看。
- 首页：查看个人任务概览、最近想法和 Skill 缓存状态。

任务计划只管理个人事项，不执行定时任务，也不与商务跟进自动同步。商务模块的 AI 整理通过本机 Codex 能力执行；AI 只生成草稿，不会自动推进业务阶段、发送消息或修改正式数据。Codex 不可用时，手动商务管理仍可正常使用。

## 数据

- SQLite：`data/workbench.sqlite`（同时会产生 WAL 文件）。
- 消息状态、任务计划、商务数据、复盘、Skill 来源覆盖和缓存均保存在 SQLite 中。
- 任务计划采用软删除，可从“最近删除”恢复；当前版本不自动永久清理。

## 安全边界

服务只接受 `127.0.0.1`、`localhost` 或 `::1`。写请求需要启动时生成的本机会话令牌与正确 Origin；不要把 API 端口转发到公网。API 默认端口为 4310，前端开发服务器为 5173。

AI 周报机器写入接口使用独立环境变量 `WORKBENCH_INTEGRATION_TOKEN`。该值必须与 `ai-weekly` 的 `WORKSPACE_TOKEN` 一致，不能复用浏览器会话令牌，也不能提交到仓库。

## 验证

```powershell
pnpm check
pnpm test:integration
```

当前自动化检查覆盖数据库迁移、任务计划分组与生命周期、API、组件和安全边界。真实 Codex Skill 能力验证可通过 `pnpm verify:codex` 手动执行，且不会修改真实 Skill 配置。
